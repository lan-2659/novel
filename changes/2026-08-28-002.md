# 2026-08-28-002 首页 AI 创意灵感生成（REQ-017）

## 时间与用户需求

- **时间**：2026-08-28
- **需求**：首页「开始一部新小说」增加「✨ 灵感创意」入口——点击后由大模型随机生成 3~5 个小说创意（标题/创意简介/题材/Hook），用户选择一个后自动填入创意输入框（书名可自动填入标题），可继续编辑后走原有创建流程。**AI 只提供灵感，不自动创建项目**。MVP 不做推荐/画像/记忆/评分/质量判断。

## 实现内容

- **用户要求**：新增 `POST /api/ideas/generate`（count/genre/style），前端入口 + 创意卡片 + 选择填入，保留原创建流程。
- **实现方式**：
  - Prompt：`pipeline/prompts.py` 新增 `IDEA_SYSTEM` + `build_idea_messages(count, genre, style)`，强制输出 `{"ideas":[{"title","idea","genre","hook"}]}`。
  - Service：新增 `services/idea_service.py`（`IdeaService.generate_ideas`）——校验 count（1~5，越界抛 400）、拼 prompt、`llm.generate_json`、字段归一化（title/idea/genre/hook 缺省补齐）；创意不落库。
  - API：新增 `api/ideas.py` 路由 `POST /api/ideas/generate`；`schemas/entities.py` 新增 `IdeaRequest/IdeaOut/IdeaListOut`；`api/deps.py` 增 `get_idea_service`；`main.py` 注册 `ideas` 路由。
  - 前端：`index.html` 创建卡片增加「✨ 灵感创意」按钮与灵感面板（加载态、创意卡片：标题+题材徽章+Hook+简介、「使用这个创意」「关闭」）；`app.js` 增 `ideas/showIdeas/ideasLoading` 状态与 `generateIdeas/useIdea/closeIdeas`；`useIdea` 将 `newPremise=idea.idea`、`newTitle=idea.title`；`style.css` 增创意卡片样式。创建流程零改动。
- **涉及文件**：`backend/app/pipeline/prompts.py`、`services/idea_service.py`（新增）、`schemas/entities.py`、`api/ideas.py`（新增）、`api/deps.py`、`main.py`、`frontend/index.html`、`frontend/app.js`、`frontend/style.css`、`backend/tests/conftest.py`、`backend/tests/test_api.py`、`README.md`、`.tasks/**`。
- **关联 Task**：TASK-024 ~ TASK-029（见 `.tasks/tasks.json`）。
- **验证方式与结果**：
  - `pytest` 12 个用例全部通过（假 LLM 新增「创意策划师」分支，返回 3 条固定创意；新用例覆盖结构、题材/风格透传、count 越界 400、默认 count）。
  - 启动验证 + 真实 DeepSeek 端到端验证通过：点击「✨ 灵感创意」→ 生成 5 个创意（时间修补师/味觉记忆馆/第七次重生/无声字母表/影子裁缝）→ 选择「时间修补师」→ 创意输入框与书名自动填入 → 创建项目「时间修补师」成功（沿用原流程）。

## 遇到的问题与解决方式

1. **前端面板布局**：灵感面板若在卡片内展开会与项目列表混在一起。解决：面板置于创建卡片内部、`border-top: dashed` 分隔，加载/空态/列表三种状态清晰展示。
2. **LLM 返回字段不确定**：个别创意可能缺 hook 或缺 idea。解决：`IdeaService._normalize` 兜底（title 缺省「未命名创意」、genre 缺省「未知」），前端结构稳定。

## 经验总结

- **「只提供灵感、不自动建项目」的边界**：AI 生成结果只回填输入框，创建动作始终由用户触发，需求边界清晰，实现也简单（无状态、无落库、无额外权限）。
- **复用 `generate_json` + system 分支**：创意生成直接复用 DeepSeek Client 的 JSON 解析/重试能力，测试用假 LLM 按 system 关键词（「创意策划师」）分支即可隔离，与既有各生成阶段测试风格一致。
- **轻量功能无需新增抽象**：IdeaService 无数据库依赖，但仍按现有「API → Service → LLM」分层放置，保持代码一致性，避免路由直连 LLM。
